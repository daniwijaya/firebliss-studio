# Firebliss Design Studio

Standalone Next.js project. Run with `npm install` then `npm run dev`.

Before launch, replace the typographic wordmark with the provided Firebliss logo, replace clearly marked concept placeholder records in `src/data/site.ts` with approved studio case studies and artwork, configure the actual contact email and social links, and connect the inquiry form in `src/components/ui.tsx` to a backend. The form currently validates locally and explicitly does not send messages. Set `NEXT_PUBLIC_SITE_URL` to the production URL for Open Graph metadata. No real studio address, social URL, client result, or testimonial is invented.
